Projet personnel

Reception radio SDR

OpenWebRX+PythonRTL-SDR et SDRplay

Une station radio logicielle accessible depuis le web avec plusieurs profils de reception.

Le projet

La station utilise un SDRplay RSPdx pour ecouter plusieurs types de signaux : FM, AM, LSB, USB et CW.

OpenWebRX+ permet d'acceder aux recepteurs depuis une interface web et de choisir les profils de reception que je veut écouter. Le + avec ce logiciel est qu'il peut décoder le signal reçus.

Si vous voulez voir ce que ça donne, vous pouvez descendre dans le site pour voir la page de la station. Comme je l'ai dit plus haut, le + de ce logiciel est sa capacité à décoder les signaux reçus. Essayer les modes JT9, FT8 et autres modes de communication en cliquant sur les tags vert.

Pour des raisons de sécurité et de performance, la station acceuil un nombre limité d'utilisateurs à la fois.

funfact 1 : Les conditions d'écoute peuvent varier en fonction de l'heure de la journée et des conditions atmosphériques.

funfact 2 : L'antenne que j'utilise est une antenne de poste radio. Comme celle qu'avait vos grands-parents. Je dois la changer pour une antenne plus adaptée aux fréquences utilisées.

Points techniques

  • Configuration de recepteurs SDR varies
  • Profils OpenWebRX+ pour plusieurs usages
  • Reception DAB+, AIS, aviation, FM, AM et shortwave
  • Création d'un script Python pour automatiser la gestion des profils sur un compte Discord
