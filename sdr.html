Projet personnel

Reception radio SDR

OpenWebRX+PythonRTL-SDR

Une station radio logicielle accessible depuis le web avec plusieurs profils de reception.

Le projet

La station utilise un SDRplay RSPdx et un Nooelec NESDR pour ecouter plusieurs types de signaux : DAB+, AIS, aviation et NOAA.

OpenWebRX+ permet d'acceder aux recepteurs depuis une interface web et de partager les profils de reception.

Points techniques

  • Configuration de recepteurs SDR varies
  • Profils OpenWebRX+ pour plusieurs usages
  • Reception DAB+, AIS, aviation et NOAA
  • Automatisation de taches avec Python
