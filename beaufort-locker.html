Beaufort Locker

ESP32PHPMySQLRaspberry Pi

Une solution type "Amazon Locker" pour la distribution automatique de fromages Beaufort AOP.

Le projet

Beaufort Locker permet aux clients de commander du fromage en ligne via une interface web publique, puis de retirer leur commande dans un casier physique dedie. Une interface d'administration hebergee localement (sur Raspberry Pi) permet de superviser l'occupation des casiers et de recevoir des alertes en temps reel.

Un module ESP32 embarque des capteurs de temperature et d'humidite pour surveiller les conditions de conservation du fromage a l'interieur des casiers, et remonte ces donnees ainsi que des alertes vers le systeme central.

Points techniques

  • Interface publique client (commande et suivi de retrait)
  • Tableau de bord de supervision pour l'administration des casiers
  • API PHP et Python recevant les donnees de l'ESP32 (temperature, humidite, alertes)
  • Base de donnees MySQL avec schema, procedures stockees et donnees d'initialisation
  • Firmware ESP32 pour la gestion des capteurs et des alertes
